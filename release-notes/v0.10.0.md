SDR Toolkit now runs on Windows, and there's an Android app.

**Windows** (10 and 11, 64-bit): download `SDR-Toolkit-Setup-0.10.0.exe` below and run it; no
administrator password needed. It updates itself like the Linux version.

- Every speaker-audio mode with the app's own decoders (Morse, RTTY, PSK, NAVTEX, SSTV, weather fax,
  DTMF/CTCSS/DCS), listening to an output device through WASAPI loopback.
- Spectrum & receiver, with an RTL-SDR on the PC (the RTL-SDR tools come with the app; the dongle
  needs the WinUSB driver, from Zadig or SDR Tools Relay's installer) or a relay.
- Connect relay…, the Satellite tracker, the Logbook and Replay.
- Modes that run outside programs (FT8/FT4, APRS, pagers, ISM, DMR) work once the program is there:
  **How to get it** says where each comes from. ADS-B, the GPS fix and LoRa need programs with no
  Windows version yet.

**Android** (`android/`): Spectrum & receiver and ADS-B on a phone, with an RTL-SDR plugged into it
or any SDR Tools Relay. Its APK is built by the Android workflow.

**Linux**: nothing changes, except that the tests now report a missing outside program as skipped
(naming it) instead of failing, and LoRa no longer fails to load where GNU Radio isn't installed.

**Tested:** on Linux, the full test suite and the window test on a PC with every outside program
installed (and an RTL-SDR plugged in, which the tests leave alone). On Windows, the build machines
built the installer and ran the tests and the app's self-test (Morse decoded, NFM demodulated, the
helper processes and bundled RTL-SDR tools working). **Not yet tried:** Windows sound devices and a
real dongle on a Windows PC, and the Android app on a real phone.
