**DMR / P25 calls: one recording per transmission, with its talkgroup and radio**

- A wide-area network sends each call out on several sites at once, so the explorer heard and saved it once per channel: two or three copies of the same transmission. Now only the longest copy is kept (the one heard best: DSD-FME stops a call's file when it loses the signal) and the others are deleted. Copies are recognised by the same talkgroup and radio at overlapping times on different channels. If a better copy finishes after a worse one was listed, the worse one is swapped out.
  - Pieces of one call on a single channel (DSD-FME lost the signal and found it again) are all kept.
  - Calls from an unknown radio are never merged.
  - When the DMR / P25 page opens, copies already saved are tidied up the same way.
- Fix: calls saved live showed no talkgroup or radio. DSD-FME names files with the protocol and colour code ("…_DMR_CC_1_GROUP_TGT_10140027_SRC_140205.wav"), which wasn't read. Talkgroup, radio, call type and colour code now come through, and the colour code names the call's network when the explorer doesn't know it yet.

Tested on a copy of real calls saved here: 74 files became 54 calls, every copy pair was resolved, and all have their talkgroup and radio. A 21.8 s transmission heard whole on one channel was kept over two shorter pieces of it on another. Also tested with made-up call files covering copies, pieces on one channel, unknown radios and a better copy arriving later.
